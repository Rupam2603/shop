## 🎨 The Design (At a Glance)

### Color Story
```
PRIMARY:    #0F766E Teal      (Trust, brand, primary actions)
SECONDARY:  #EF6461 Coral     (Energy, urgency, secondary actions)
ACCENT:     #F59E0B Amber     (Alerts, warnings, attention)
SURFACE:    #F8FFFE Off-white (Clean backgrounds)
TEXT:       #0D1117 Navy      (High contrast text)
NEUTRAL:    #9CA3AF Gray      (Secondary text, dividers)
```

### Typography
```
DISPLAY:   Manrope (700–800)  → Headlines, CTAs, brand statements
BODY:      Inter (400–600)    → Body copy, UI text, labels
SCALE:     h1: 3.5rem → h6: 1rem → Caption: 0.75rem
```

### Key Principle
**One bold choice per section**: Teal hero is memorable, everything else is disciplined.

